# CONTROL DECK C-07

艶のある床とホログラムの管制デッキと、隣の私室を、主観視点で歩けるブラウザ用の 3D 空間です（試作。ゲームの目的はまだありません）。
モデル、照明、音はコードで生成しています。画像は、惑星の地表と雲、鉱石の表示の3枚だけです。

公開先

- https://wedgew00d.github.io/control-deck-c07/
- https://wedgew00d.github.io/control-deck-c07/?openExternalBrowser=1 （LINE に貼る用。外部ブラウザで開きます）

## 遊び方

| 操作 | PC | スマホ |
|---|---|---|
| 移動 | W A S D（SHIFT で早歩き） | 画面の左半分をドラッグ |
| 視点 | マウス | 画面の右半分をドラッグ |
| 操作 | E（またはクリック） | ACT ボタン |
| メニュー | ESC | 右上の II |

管制デッキ C-07

- 中央の床のパッド：乗るとホログラムが起動する（離れると消える）
- 西の卓：アクセント色の切り替え（AMBER / ICE / ROSE）
- 東の扉：近づくと開く。先が私室

私室 C-08

- シャワー：出す／止める
- ベッド：横になる（動くと立つ）
- ソファ：座る（動くと立つ）
- 机の端末：照明の切り替え（WORK / REST）

メニュー

- QUALITY：軽量／標準／高。PC は標準、スマホは軽量で始まります。
  - 軽量：アンビエントオクルージョン（AO）なし、床の反射は低い解像度
  - 標準：AO あり（半分の解像度）、輪郭は FXAA
  - 高：AO あり、マルチサンプル4倍
- REFLECTION：床の平面反射の入切（重いときは切る）
- FULLSCREEN、SOUND、BGM と SE の音量（値はブラウザに保存）

50fps を下回る状態が続くと、描画解像度を自動で下げます（最大で半分まで）。余裕が戻れば、一度だけ1段戻します。

## 構成

ビルドなしで、リポジトリ直下をそのまま配信します。

```
index.html        画面の枠、メニュー、スタイル
js/game.js        部屋、照明、ホログラム、操作、後処理
js/audio.js       音（Web Audio の合成）
assets/           画像3枚（惑星の地表、雲、鉱石の表示）。無くても、コードで描いた絵で動きます
lib/              three.js r170 と、後処理・AO・FXAA のモジュール（同梱）
```

- 扉が閉まっている間は、いない側の部屋を描きません。
- 惑星と大気は、起動時に一度だけキューブマップへ焼きます（雲は動きません）。
- 影は、起動時と画質の切り替え時に1回だけ計算します。

## 確認用の機能

- F3 キー、または URL に `#debug` を付ける：左下に fps、位置、画質、描画解像度、自動調整の倍率、AO と反射の状態、描画回数を表示
- ブラウザのコンソールから `window.ROOM`
  - `ROOM.pose(x, z, yaw, pitch)`：位置と向きの指定、`ROOM.walk(x, z)`：当たり判定つきで歩かせる
  - `ROOM.pad(秒)`：パッドの起動から指定の秒数が経った瞬間を出す（`ROOM.pad(null)` で戻す）
  - `ROOM.door(0/1)`、`ROOM.shower(0/1)`、`ROOM.mode(0/1)`、`ROOM.accent(0〜2)`、`ROOM.sit(0/1)`、`ROOM.mirror(0/1)`、`ROOM.quality('low'|'mid'|'high')`
  - `ROOM.freeze(t)`：時間を止める（`ROOM.freeze(null)` で戻す）、`ROOM.step(dt, n)`：n フレーム進める
  - `ROOM.ao(4)`：AO だけを表示（`ROOM.ao(0)` で戻す）
  - `ROOM.cfg({...})`：画質の設定を上書き、`ROOM.bench(n)`：n フレームを続けて描いた1フレームあたりの時間（ms）
  - `ROOM.state`：現在の状態
